# 原神跟跑助手

**GI-Follow-Assist（GIFA，原神跟跑助手）** 是一个可以 **压在原神窗口之上** 的 B 站视频悬浮窗：边跑地图边看攻略，按一下快捷键就能暂停视频，不用 alt+tab 切出去。

> 本仓库是基于 [FinalLawer/GIFA](https://github.com/FinalLawer/GIFA) 的**自用魔改版**，在原作者版本上增加了全屏弹幕投影、底部字幕精灵、转向提示、贴边吸附与若干性能优化。基础功能与实现思路来自原作者。

## 下载与安装

**最新版下载：** https://github.com/beiji321/GIFA-ZiYong/releases/latest

当前版本 **0.2.5-mod**，发布包有两种，功能完全一样，按习惯选一个：

| 版本 | 文件名 | 适合 | 设置保存在 |
| --- | --- | --- | --- |
| **便携版** | `GenshinRouteBuddy-0.2.5-mod-portable.exe` | 单文件双击即用，不写注册表，可以拷到 U 盘 | exe 同级的 `data\` |
| **安装版** | `GenshinRouteBuddy-0.2.5-mod-Setup.exe` | 想要开始菜单 / 桌面快捷方式、卸载器、开机自启 | `%APPDATA%\原神跟跑助手\` |

如果 releases 页还没有对应文件，请到 [Issues](https://github.com/beiji321/GIFA-ZiYong/issues) 反馈。

- **第一次双击会弹一次 UAC 申请管理员权限，点「是」**：全局快捷键要在以管理员权限运行的游戏里也生效，这是 Windows 的限制。
- 安装版有自定义安装页，可以选安装目录，并按需勾选「开机时自动打开启动器」「从旧绿色版迁移数据」（把旧 `data\` 里的设置和小地图标定复制过来）、「同时迁移 B 站登录态」。不勾选也没关系，重新登录一次即可。升级安装会沿用上一次的开机自启选择。
- 卸载安装版**默认不会**删掉设置和标定，重装可以接着用；想彻底清干净，在卸载向导的「卸载选项」页勾选「同时删除以上数据」即可。
- 便携版和 zip 绿色版想搬走设置，把 `data\` 一起拷走就行。

## 开始使用

1. 游戏内 → 设置 → 图像 → 显示模式，选 **窗口化** 或 **无边框**。
   不要选「独占全屏」：它会绕过 Windows 桌面合成，任何外部浮窗都盖不上去，这是系统限制。
2. 打开启动器，粘贴 B 站视频链接（BV 号、av 号、完整链接、`b23.tv` 短链、带 `?p=3` 的分 P 链接都支持）。
3. 浮窗出现后可以拖动位置、拖角缩放；标题栏点「登录」扫码登录 B 站即可看高清。
4. 浮窗已经开着时换视频，直接在启动器里贴新的 BV 号再点「启动跟跑」即可，不用先关浮窗。换片会自动清空上一部视频的弹幕、字幕与转向提示。

浮窗位置会被记住：拖到哪、贴到哪，下次启动原地恢复。

## 功能

- **永远置顶**：压在游戏窗口之上，层级被抢会自动夺回；显示时不会把游戏切到后台
- **全局快捷键**：游戏全屏、鼠标在游戏里也生效，默认 `Alt+空格` 暂停 / 播放
- **B 站网页版播放器**：自动点「网页全屏」铺满浮窗，登录后 1080P / 4K / 大会员画质正常
- **16:9 比例锁定**：标题栏一键锁定，缩放时自动按 16:9 校正，视频不出现黑边
- **纯净模式**：`Alt+Z` 隐藏全部界面，只留画面；同时开启鼠标穿透，快捷键退出
- **扫码登录**：标题栏「登录」调起扫码窗口，成功后自动关窗并按高清重载，只需登录一次
- **分 P 切换**：自动读取分 P 列表，下拉选择或快捷键切换，下拉框会标出当前 P
- **上次看到**：下次启动可以接着播上次看的视频
- **鼠标穿透**：控制台里的独立开关，开启后点击直接落到游戏里，浮窗只做显示；纯净模式会自动强制穿透
- **不透明度 / 音量 / 倍速 / 拖动进度 / 拖角缩放**，设置与窗口位置自动记忆
- **全屏弹幕投影**：见下文
- **底部字幕精灵**：见下文
- **转向提示**：见下文
- **贴边吸附**：见下文
- **小地图方位标记**：见下文

## 快捷键

| 功能 | 默认键 |
| --- | --- |
| 播放 / 暂停 | `Alt+空格` |
| 后退 5 秒 | `Alt+←` |
| 前进 5 秒 | `Alt+→` |
| 上一分 P | `Alt+↑` |
| 下一分 P | `Alt+↓` |
| 隐藏 / 显示浮窗 | `Alt+H` |
| 半透明 开 / 关 | `Alt+O` |
| 纯净模式 开 / 关 | `Alt+Z` |

全部可在 ⚙ 设置里点击对应的键位重新录制（需要至少一个修饰键，F1–F12 可单独使用）。

**鼠标侧键**：点击任意键位后直接按鼠标侧键，即可把「后退 / 前进」侧键绑上去，录完显示为 `鼠标侧键 ◀` / `鼠标侧键 ▶`。也可以录制 `右键 + 侧键` 的组合键。侧键是系统级被动监听，游戏全屏、焦点在游戏里时照样触发，且不会吞掉游戏里的右键操作。

> 如果侧键同时被鼠标驱动软件（罗技 G HUB、雷蛇等）绑定了宏，可能会被驱动先截走，触发不到；把驱动里的绑定清掉即可。

## 登录与画质

B 站现在很多视频必须登录才能完整观看，未登录时播放器只给预览或标清：

1. 点标题栏右上角的 **「登录」**（登录后变成一个绿点），弹出 B 站扫码窗口
2. 手机 B 站扫一扫，登录成功窗口会自动关闭
3. 浮窗自动重载当前视频，画质上限随之提升

之后每次启动都是登录状态。如果登录后仍然提示受限（会员专享、付费内容、充电专属视频等），那属于账号权限问题。

> 网页版播放器的首屏会比嵌入播放器慢一两秒，换来的是完整画质。

## 全屏弹幕投影

把 B 站视频的弹幕画到**整个屏幕**上，铺满游戏画面之上，而不是挤在浮窗里。

- 数据源是 B 站官方弹幕接口，按视频的 `cid` 拉取，不是从播放器 DOM 里抠
- 按播放进度只下发「当前时间点前 1 秒 ~ 后 6 秒」的片段，本地时钟插值，到点才弹
- 轨道碰撞检测：某条轨道排满时**直接丢弃**该条弹幕，不叠字
- 暂停视频时弹幕同步暂停：冻结时钟、停掉渲染循环，屏幕上正在飞的弹幕定在半空
- 弹幕在**方位标记附近会自动挖空**：小地图上的红绿箭头那一圈始终干净，不会被弹幕糊住

可在启动器 → B 站设置里调整显示区域、不透明度、字号、速度、字重、同屏上限与黑色描边。

## 底部字幕精灵

把 B 站视频的字幕贴到**屏幕底部**，像电视字幕一样，与浮窗位置无关。

- 自动点开播放器字幕按钮；对只有 AI 字幕的视频，会进一步在语言菜单里选择中文
- 字幕面板的固定 UI 文案（如「字幕设置」）会被过滤，不会当成台词显示
- 3 秒无新字幕自动淡出，容器同时置为不可见，不会留下空黑框
- 可按幕调整字号、颜色、描边方式（无 / 四向黑边 / 单向投影）、位置、垂直偏移、背景不透明度、字重、圆角、最大宽度与停留时长

## 转向提示

从字幕文本里识别行进方向，在屏幕边缘弹出一枚发光箭头：

- 左 / 右 → 贴左右边缘；上 / 下 → 贴上下边缘
- 「抬头 / 低头」「往上看 / 往下看」也归入上 / 下
- 词表匹配而非单字匹配，避免「左右」「上面有个宝箱」这类叙述误触发
- 左右与上下**可以分组独立开关**
- 可调贴边距离、上下位置、左右位置、提示大小、停留时长、不透明度与颜色

## 贴边吸附

把浮窗拖到屏幕边缘附近（20px 以内）时，浮窗内侧会亮起一条蓝色发光边线，松手即吸附到该边缘。贴近角落时两条边会同时亮起。

- 补偿量按当前显示器的缩放比例（DPI）自动换算，换分辨率或改缩放后不需要手动调整
- 边缘仍有 1~2px 缝隙或切边时，可在 浮窗 → 吸附微调 里用滑块（-20 ~ +20px）微调，拖动即刻生效
- 未做强制层级抢占，弹幕层与浮窗的叠放关系由方位标记挖空保证

## 小地图方位标记

叠加层会在屏幕上画两个标记：**红色箭头**是视频里博主正在行进的世界方位，**绿色圆弧**是镜头 / 视野朝向。两者互相独立，站着转视角时方向差很多是正常的。标记画在屏幕坐标系上，所以不管你自己的小地图是固定北朝上还是随角色旋转都能用。

前提只有一个：**视频里的小地图必须固定北朝上**。如果是随角色旋转的，中央箭头恒朝上，世界方位信息根本不存在。

### 标定

- ⚙ → ① 框选视频里的小地图 → 拖动圆环对准箭头支点 → 滚轮调大小 → 完成
- **圆心不用手动对到像素级**：点「③ 自动定心」后程序会从画面里找箭头支点，算准一次就写进这个视频的标定并固定住；圆环大致套住小地图即可
- 同一个视频里，平时是游戏原生的小地图，讲到路线时常换成剪辑放大的地图贴片，位置和大小完全不同，所以**可以框多处**（位置重合则替换，最多 4 处），每帧自动挑最可信的一块
- 标定结果**按视频记住**，换视频不用重框
- 转场、特写、对话时画面里没有小地图，标记会自动收起

### 一个必须接受的局限

这是**够用级**方案，不是导航级：地形干扰、传送锚点图标、角色朝向 ≠ 行进方向（回头打怪时朝向立刻反向），都会让结果偏离。实测在正常游玩画面上误差约 ±10~20°，大方向可用，精确定位不行。

## 已知限制

- 独占全屏下无法覆盖（请改成窗口化 / 无边框）
- 部分游戏使用 Raw Input 独占键盘，若快捷键失效，在设置里换成别的组合键
- 必须登录才有 1080P / 4K，未登录时 B 站自己只放预览或标清
- 网页版首屏比嵌入播放器慢一两秒
- 弹幕与字幕依赖 B 站接口 / 页面结构，B 站改版后可能失效，需要更新选择器
- 未做代码签名，首次运行 SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」即可
