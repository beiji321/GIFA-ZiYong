第一次使用

按这三步走，基本不会踩坑

1游戏内「图像 → 显示模式」改成 窗口化 或 无边框；独占全屏下系统不允许任何浮窗盖上去。
2在「方位标定」里开启箭头，把标记摆到你的游戏小地图上。视频布局不同时再新增布局。
3回到游戏，用快捷键暂停 / 快进。默认 Alt+空格 暂停播放。
游戏里看不到浮窗？

在原神的「设置 → 图像 → 显示模式」选择「窗口化」或「无边框」。如果已经隐藏了浮窗，可用上方的显示快捷键找回。

全局快捷键

点击键位后按下新的按键、组合键或鼠标侧键。按 Esc 取消录制。

键盘与鼠标

快捷键和游戏按键冲突时

单键、侧键和两个倍速动作会同时传给游戏。可以换成游戏里较少用的键。其他组合键由助手独占。

手柄快捷键

按住左摇杆（PS 的 L3 / Xbox 的 LS）打开圆盘，推右摇杆选择动作，回中执行。提前松开左摇杆可取消。「长按加速」在推到该方向时开始，离开方向或松开左摇杆即恢复。
