# 原神跟跑助手

**GI-Follow-Assist（GIFA，原神跟跑助手）** 是一个可以 **压在原神窗口之上** 的 B 站视频悬浮窗：边跑地图边看攻略，按一下快捷键就能暂停视频，不用 alt+tab 切出去。

## 关于应用内更新

**本自用版已停用应用内更新**，启动器不显示「软件更新」入口。

原因：上游的更新器固定指向 `FinalLawer/GIFA`，并要求 Release 附带用作者私钥签名的
`GIFA-update.json`。本仓库没有签名私钥、也没有发布清单，而版本号带 `-mod`
（不符合它要求的 `X.Y.Z` 格式），所以实际运行时只会显示「当前运行方式不支持应用内更新」。
若把版本号改成纯数字反而更糟 —— 它会去拉原作者的正版，把自用功能全部覆盖。

升级方式：直接下载本仓库新发布的安装包 / 绿色版覆盖即可。
安装版会保留原安装目录与用户数据（`%APPDATA%\原神跟跑助手\`）；
绿色版请把旧的 `data\` 目录一起保留。

上游的原始说明保留在 [HOT-UPDATE.md](HOT-UPDATE.md)，仅供查阅，不适用于本自用版。

## 开始使用

1. 游戏内 → 设置 → 图像 → 显示模式，选 **窗口化** 或 **无边框**。
   不要选「独占全屏」：它会绕过 Windows 桌面合成，任何外部浮窗都盖不上去，这是系统限制。
2. 在启动器的「启动」页粘贴 B 站链接或 BV 号，按回车或点「打开浮窗」。也支持 av 号、`b23.tv` 短链和带 `?p=3` 的分 P 链接。已有观看记录时可直接点「继续观看」。
3. 浮窗出现后可以拖动位置、拖角缩放；标题栏点「登录」扫码登录 B 站即可看高清。

## 功能

- **永远置顶**：压在游戏窗口之上，层级被抢会自动夺回；显示时不会把游戏切到后台
- **全局快捷键**：游戏全屏、鼠标在游戏里也生效，默认 `Alt+空格` 暂停 / 播放
- **B 站网页版播放器**：自动点「网页全屏」铺满浮窗，登录后 1080P / 4K / 大会员画质正常
- **16:9 比例锁定**：标题栏一键锁定，缩放时自动按 16:9 校正，视频不出现黑边
- **纯视频沉浸**：`Alt+I` 隐藏全部界面，只留画面；同时开启鼠标穿透，快捷键退出
- **扫码登录**：标题栏「登录」调起扫码窗口，成功后自动关窗并按高清重载，只需登录一次
- **分 P 切换**：自动读取分 P 列表，下拉选择或快捷键切换，下拉框会标出当前 P
- **上次看到**：下次启动可以接着播上次看的视频
- **鼠标穿透**：开启后点击直接落到游戏里，浮窗只做显示
- **纯视频沉浸**：隐藏控件、锁定移动缩放并穿透鼠标。窗口临时贴合视频原比例，不拉伸也不裁切；退出后恢复原位置和尺寸。视频源自己带的黑边不会被裁掉。
- **鼠标自动避让**：沉浸时移入浮窗自动降到 10% 不透明度，移出恢复，不覆盖保存的透明度
- **倍速快捷键**：常规倍率按 `1 → 1.25 → 1.5 → 2` 循环并提示；长按使用可选的临时倍率，松开恢复常规倍率
- **不透明度 / 音量 / 倍速 / 拖动进度 / 拖角缩放**，设置与窗口位置自动记忆
- **全屏弹幕投影**：见下文
- **底部字幕精灵**：见下文
- **转向提示**：见下文
- **贴边吸附**：见下文
- **小地图方位标记**：见下文

## 快捷键

| 功能 | 默认键 |
| --- | --- |
| 播放 / 暂停 | `Alt+空格` |
| 后退 5 秒 | `Alt+←` |
| 前进 5 秒 | `Alt+→` |
| 上一分 P | `Alt+↑` |
| 下一分 P | `Alt+↓` |
| 隐藏 / 显示浮窗 | `Alt+H` |
| 鼠标穿透 开 / 关 | `Alt+L` |
| 半透明 开 / 关 | `Alt+O` |
| 纯视频沉浸 开 / 关 | `Alt+I` |
| 循环常规倍速 | `Alt+S` |
| 长按临时加速，松开恢复 | `F8` |

全部可在 ⚙ 设置里点击对应的键位重新录制，支持单键、组合键和鼠标侧键。循环倍速与长按加速走被动监听：按住不会连续切档，也不拦截同名游戏按键；其他组合键由系统独占。录制时会暂停触发，冲突时交换绑定，交换后任一动作注册失败则整体回滚。

「浮窗设置」页可开关纯视频沉浸、鼠标移入自动变淡，并选择长按倍率 `1.25 / 1.5 / 2 / 2.5 / 3`（默认 2）。沉浸状态和临时加速不在重启后自动开启；退出沉浸恢复原穿透和透明度。常规倍率会跨分 P 和重启记住，临时加速不会覆盖它。长按时切 P 保持临时倍率，松开回到常规倍率；改绑、关闭窗口、休眠或锁屏也会取消临时加速。

**鼠标侧键**：点击任意键位后直接按鼠标侧键，即可把「后退 / 前进」侧键绑上去，录完显示为 `鼠标侧键 ◀` / `鼠标侧键 ▶`。也可以录制 `右键 + 侧键` 的组合键。侧键是系统级被动监听，游戏全屏、焦点在游戏里时照样触发，且不会吞掉游戏里的右键操作；浏览器里侧键的前进后退也不受影响。

> 如果侧键同时被鼠标驱动软件（罗技 G HUB、雷蛇等）绑定了宏，可能会被驱动先截走，触发不到；把驱动里的绑定清掉即可。

### 手柄快捷键

- PS4 DualShock 4、PS5 DualSense 和 DualSense Edge 可以通过 USB 或 Windows 蓝牙配对直接连接。
- Xbox 360、One、Series X|S 和兼容手柄使用 Windows 的 XInput，连接方式取决于手柄型号。

打开「快捷键 → 手柄快捷键」查看识别状态。按住左摇杆（PlayStation 的 L3 / Xbox 的 LS），推右摇杆选择扇区，回中执行。多人同时连接时，先按下左摇杆的手柄控制这次圆盘，松开后其他手柄可用。断开正在操作的手柄会取消该次选择并结束它的临时加速。

如果同一只手柄同时显示为 PlayStation 手柄和 Xbox / XInput，可以在 Steam Input 或 DS4Windows 中只保留一种设备输出。仅用键鼠时可关闭「启用手柄快捷键」，后台检测会停止，八方向绑定会保留。

## 登录与画质

1. 点启动器右上角的 **「登录 B 站」** 打开扫码窗口。登录后此处显示账号昵称，也可以点昵称切换账号。

3. 浮窗自动重载当前视频，画质上限随之提升

## 全屏弹幕投影

把 B 站视频的弹幕画到**整个屏幕**上，铺满游戏画面之上，而不是挤在浮窗里。

- 数据源是 B 站官方弹幕接口，按视频的 `cid` 拉取，不是从播放器 DOM 里抠
- 按播放进度只下发「当前时间点前 1 秒 ~ 后 6 秒」的片段，本地时钟插值，到点才弹
- 轨道碰撞检测：某条轨道排满时**直接丢弃**该条弹幕，不叠字
- 暂停视频时弹幕同步暂停：冻结时钟、停掉渲染循环，屏幕上正在飞的弹幕定在半空
- 弹幕在**方位标记附近会自动挖空**：小地图上的红绿箭头那一圈始终干净，不会被弹幕糊住

可在启动器 → B 站设置里调整显示区域、不透明度、字号、速度、字重、同屏上限与黑色描边。

## 底部字幕精灵

把 B 站视频的字幕贴到**屏幕底部**，像电视字幕一样，与浮窗位置无关。

- 自动点开播放器字幕按钮；对只有 AI 字幕的视频，会进一步在语言菜单里选择中文
- 字幕面板的固定 UI 文案（如「字幕设置」）会被过滤，不会当成台词显示
- 按**视频进度**判断过期（默认 3 秒），暂停时字幕保持不动，容器同时置为不可见，不会留下空黑框
- 可按幕调整字号、颜色、描边方式（无 / 四向黑边 / 单向投影）、位置、垂直偏移、背景不透明度、字重、圆角、最大宽度与停留时长

## 转向提示

- 在「方位标定」里开启箭头，按视频选择「你的影月月」或「提瓦特高级特工穿山甲」的放大小地图布局。在「游戏里的标记」点「摆放方位标记」，即可调整标记在屏幕上的位置。
- 如果博主的视频布局不同，点「新增布局」，输入名称（例如博主昵称），在浮窗拖动圆环、用滚轮调大小，然后点「完成」。圆环大致套住小地图即可，播放时程序会自动尝试对准圆心。需要重试时，展开「识别工具」，点「重新对准圆心」。
- 当前布局跨视频和分 P 保持；可选择下次启动使用的布局。已有多个布局时，可在启动器或浮窗标题栏切换。**每帧只从当前一块视频区域识别**，红箭头和绿弧分别计算，不轮询其他布局。
- 旧版标定会迁成命名布局，可重命名使用；持续未识别到小地图时可切换或新增布局。

- 左 / 右 → 贴左右边缘；上 / 下 → 贴上下边缘
- 「抬头 / 低头」「往上看 / 往下看」也归入上 / 下
- 词表匹配而非单字匹配，避免「左右」「上面有个宝箱」这类叙述误触发
- 左右与上下**可以分组独立开关**
- 可调贴边距离、上下位置、左右位置、提示大小、停留时长、不透明度与颜色

## 贴边吸附

把浮窗拖到屏幕边缘附近（20px 以内）时，浮窗内侧会亮起一条蓝色发光边线，松手即吸附到该边缘。贴近角落时两条边会同时亮起。

- 补偿量按当前显示器的缩放比例（DPI）自动换算，换分辨率或改缩放后不需要手动调整
- 边缘仍有 1~2px 缝隙或切边时，可在 浮窗 → 吸附微调 里用滑块（-20 ~ +20px）微调，拖动即刻生效
- 未做强制层级抢占，弹幕层与浮窗的叠放关系由方位标记挖空保证

Windows x64 环境使用 Node.js 22.12 或更新版本，推荐 Node.js 24；依赖版本由 `package-lock.json` 固定。本次发布使用 Electron 45.2.3 和 electron-builder 26.18.0。`npm start` 和 Windows 打包流程会用系统 .NET Framework 4.x 的 C# 编译器构建手柄辅助程序。打包流程会将它放入绿色版和安装版的 `resources` 目录。

```powershell
npm.cmd ci
npm.cmd run test:license
npm.cmd run test:materials
npm.cmd run test:data-dir
npm.cmd run test:controls
npm.cmd run test:gamepad
npm.cmd run test:login
npm.cmd run test:sandbox

```

`pack:release` 自动选择全新的 `dist-release-N/`，产出绿色版 ZIP、安装版 EXE 和 `SHA256SUMS.txt`。只需从源码构建时，不需要实拍素材；视觉回归的额外样本依赖见下文。必要图标与安装器资源已随源码提供，无须重新生成。

发行页的源码 ZIP 对应所注明的提交；`uiohook-napi-1.5.5-source.tgz` 是锁文件对应的原始 npm 包，另附在发行页，供审查和重建原生组件使用，不会放进普通用户安装目录。当前源码及构建脚本按 GPL-3.0-only 提供，第三方组件各自的许可不变。

## 项目维护

待修复问题、用户需求与验收条件见 [ISSUES.md](ISSUES.md)；目录和提交约定见 [AGENTS.md](AGENTS.md)。

以本仓库目录为起点，外部目录约定如下（都不属于 Git 提交范围）：

| 目录 | 用途 |

| `../_materials/GIFA/vision-probe/fixtures/` | 实拍图像、标注图与原始像素样本 |
| `../_materials/GIFA/vision-probe/reports/` | 视觉实验报告与门控标签归档 |

开发工具通过 `scripts/material-paths.js` 定位素材，默认路径不依赖启动命令所在目录；也可用环境变量 `GIFA_MATERIALS_DIR` 指定其他仓库外位置。截图、裁剪、抽帧和对照图输出均拒绝仓库内部路径。资源预览示例：`python scripts/make-assets.py --preview=../_preview`。

三份 `scripts/vision-probe/vid-times-*.json` 是抽帧参数配置，保留在项目中；本机视频位置等私有配置放在外部素材目录的 `vision-probe/video-conf.json`。现有 166/500 帧回归二进制数据仍读取系统临时目录，不会复制到仓库。`vid-times-roi.json` 默认导出 PNG，不能直接当作 166 帧二进制数据的重建命令。

可运行 `npm.cmd run test:materials` 检查路径边界，`npm.cmd run test:license` 检查许可一致性，`npm.cmd run test:cone` 检查视锥，`npm.cmd run test:snow` 检查雪地近白背景和用户视频抽样。`npm.cmd run test:bearing-view` 检查视角挂起及箭头漏检时视角独立上报。`npm.cmd run test:bearing-pixels` 用合成图核对青色分位数、不同布局与微移裁片的原始像素，以及两路识别结果。实拍数据缺失时须留意 `SKIP`；`test:autocenter` 需要本机 500 帧数据，完整测试依赖见问题清单。

`npm.cmd run test:controls` 验证按下/松开、物理重复去重、重挂后的释放屏障、快捷键冲突事务、沉浸窗口与鼠标避让、常规与临时倍率隔离；不启动业务应用、不读写用户配置。游戏内鼠标和权限行为仍需实机验收。

`npm.cmd run test:gamepad` 覆盖八方向选择、混合设备、断连取消和临时倍速恢复。Windows 上还会编译手柄辅助程序，回放 Xbox 状态以及索尼手柄的 USB 和蓝牙输入报告。实体手柄连接和原神前台操作需实机验收。

`npm.cmd run test:login` 离线验证登录入口不依赖浮窗、登录窗口前台显示、重复点击恢复、登录成功广播和轮询异步竞态；不连接 B 站、不读取用户配置。

`npm.cmd run test:sandbox` 验证沙箱启动失败兜底：先做离线回归，再用隔离的 Electron 和一个不存在的 `--gpu-launcher` 模拟 GPU 进程创建失败，检查记标记、带开关重启、兼容模式生效和失败对话框。测试数据放在系统临时目录并自动清理；模拟不能代替受影响系统上的实机验收。

`npm.cmd run test:playback` 验证音量、静音、倍速的保存和恢复：先做离线设置文件与 IPC 回归，再用隔离的 Electron 和本地媒体页面验证首次自动播放、换源、替换视频元素、页面重载和延迟创建视频。测试数据放在系统临时目录并自动清理，不启动业务窗口、不读取用户配置，也不连接 B 站；真实 B 站播放器的手动切 P、自动连播仍需实播验收。
