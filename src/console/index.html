第一次使用

按这三步走，基本不会踩坑

1游戏内「图像 → 显示模式」改成 窗口化 或 无边框；独占全屏下系统不允许任何浮窗盖上去。
2在「方位标定」里开启箭头，把标记摆到你的游戏小地图上。视频布局不同时再新增布局。
3回到游戏，用快捷键暂停 / 快进。默认 Alt+空格 暂停播放。

播放倍速

常规倍速会记住，长按加速只临时生效

按住 F8 临时加速，松开恢复常规倍速；临时值不会替换保存的常规倍速。

按 Alt+S 循环切换常规倍速：1 → 1.25 → 1.5 → 2 倍；可在「快捷键」中修改。

全局快捷键

点键位后按下新组合，也可以只按一个键，或直接按鼠标侧键。

键位 游戏全屏时同样生效

单键、侧键、循环倍速与长按动作走被动监听；其他组合键由系统独占

单键（如 F9、J）、鼠标侧键、循环倍速和长按临时加速都走系统钩子被动监听，不占用、不拦截按键，游戏里同一个键也会照常生效，建议挑不常用的键。 循环倍速和长按动作即使绑定组合键也使用被动监听；循环倍速每按一次切一档，长按加速松开后恢复常规倍速。其他带 Alt / Ctrl 的组合键由系统独占。 沉浸模式可用同一快捷键进入和退出，也可回到「浮窗」页关闭。

手柄快捷键 按住 L3 弹出圆盘

推右摇杆指向方位，回中触发；一个动作可以绑到多个方位

左边就是弹出后的圆盘：扇区上的 n 是正北（向上推右摇杆），e 是正东，其余依此类推。圆盘只在按住 L3 时出现，抬起即收起；未回中就抬杆算取消，不会触发。 改完立刻生效，不用重启。长按加速反过来用：推过锁存线就开始临时加速，回中、滑到别的方向或抬起 L3 才恢复原倍速 —— 加速多久就是摇杆推多久。
