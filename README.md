# 原神跟跑助手

**GI-Follow-Assist（GIFA，原神跟跑助手）** 是一个可以 **压在原神窗口之上** 的 B 站视频悬浮窗：边跑地图边看攻略，按一下快捷键就能暂停视频，不用 alt+tab 切出去。

## 开始使用

1. 游戏内 → 设置 → 图像 → 显示模式，选 **窗口化** 或 **无边框**。
   不要选「独占全屏」：它会绕过 Windows 桌面合成，任何外部浮窗都盖不上去，这是系统限制。
2. 打开启动器，粘贴 B 站视频链接（BV 号、av 号、完整链接、`b23.tv` 短链、带 `?p=3` 的分 P 链接都支持）。
3. 浮窗出现后可以拖动位置、拖角缩放；标题栏点「登录」扫码登录 B 站即可看高清。

## 功能

- **永远置顶**：压在游戏窗口之上，层级被抢会自动夺回；显示时不会把游戏切到后台
- **全局快捷键**：游戏全屏、鼠标在游戏里也生效，默认 `Alt+空格` 暂停 / 播放
- **B 站网页版播放器**：自动点「网页全屏」铺满浮窗，登录后 1080P / 4K / 大会员画质正常
- **纯净模式**：自动隐藏顶栏、右侧推荐、评论区、广告
- **扫码登录**：标题栏「登录」调起扫码窗口，成功后自动关窗并按高清重载，只需登录一次
- **分 P 切换**：自动读取分 P 列表，下拉选择或快捷键切换，下拉框会标出当前 P
- **上次看到**：下次启动可以接着播上次看的视频
- **鼠标穿透**：开启后点击直接落到游戏里，浮窗只做显示
- **纯视频沉浸**：隐藏控件、锁定移动缩放并穿透鼠标。窗口临时贴合视频原比例，不拉伸也不裁切；退出后恢复原位置和尺寸。视频源自己带的黑边不会被裁掉。
- **鼠标自动避让**：沉浸时移入浮窗自动降到 10% 不透明度，移出恢复，不覆盖保存的透明度
- **倍速快捷键**：常规倍率按 `1 → 1.25 → 1.5 → 2` 循环并提示；长按使用可选的临时倍率，松开恢复常规倍率
- **不透明度 / 音量 / 倍速 / 拖动进度 / 拖角缩放**，设置与窗口位置自动记忆
- **小地图方位标记**：见下文

## 快捷键

| 功能 | 默认键 |
| --- | --- |
| 播放 / 暂停 | `Alt+空格` |
| 后退 5 秒 | `Alt+←` |
| 前进 5 秒 | `Alt+→` |
| 上一分 P | `Alt+↑` |
| 下一分 P | `Alt+↓` |
| 隐藏 / 显示浮窗 | `Alt+H` |
| 鼠标穿透 开 / 关 | `Alt+L` |
| 半透明 开 / 关 | `Alt+O` |
| 纯视频沉浸 开 / 关 | `Alt+I` |
| 循环常规倍速 | `Alt+S` |
| 长按临时加速，松开恢复 | `F8` |

全部可在启动器「快捷键」里重新录制，支持单键、组合键和鼠标侧键。循环倍速与长按加速使用被动监听，按住不会连续切档，也不拦截同名游戏按键；其他组合键由系统独占。录制时会暂停触发，冲突时交换绑定，交换后任一动作注册失败则整体回滚。

「浮窗」页可开关纯视频沉浸、鼠标移入自动变淡，并选择长按倍率 `1.25 / 1.5 / 2 / 2.5 / 3`（默认 2）。沉浸状态和临时加速不在重启后自动开启；退出沉浸恢复原穿透和透明度。常规倍率会跨分 P 和重启记住，临时加速不会覆盖它。长按时切 P 保持临时倍率，松开回到常规倍率；改绑、关闭窗口、休眠或锁屏也会取消临时加速。

**鼠标侧键**：点击任意键位后直接按鼠标侧键，即可把「后退 / 前进」侧键绑上去，录完显示为 `鼠标侧键 ◀` / `鼠标侧键 ▶`。侧键是系统级监听，游戏全屏、焦点在游戏里时照样触发；浏览器里侧键的前进后退也不受影响。

> 如果侧键同时被鼠标驱动软件（罗技 G HUB、雷蛇等）绑定了宏，可能会被驱动先截走，触发不到；把驱动里的绑定清掉即可。

## 登录与画质

B 站现在很多视频必须登录才能完整观看，未登录时播放器只给预览或标清：

1. 点标题栏右上角的 **「登录」**（登录后变成一个绿点），弹出 B 站扫码窗口
2. 手机 B 站扫一扫，登录成功窗口会自动关闭
3. 浮窗自动重载当前视频，画质上限随之提升

之后每次启动都是登录状态。如果登录后仍然提示受限（会员专享、付费内容、充电专属视频等），那属于账号权限问题。

> 网页版播放器的首屏会比嵌入播放器慢一两秒，换来的是完整画质。

## 小地图方位标记

叠加层会在屏幕上画两个标记：**红色箭头**是视频里博主正在行进的世界方位，**绿色圆弧**是镜头 / 视野朝向。两者互相独立，站着转视角时方向差很多是正常的。标记画在屏幕坐标系上，所以不管你自己的小地图是固定北朝上还是随角色旋转都能用。

前提只有一个：**视频里的小地图必须固定北朝上**。如果是随角色旋转的，中央箭头恒朝上，世界方位信息根本不存在。

### 标定

- 在「方位标定」里开启箭头，按视频选择「你的影月月」或「提瓦特高级特工穿山甲」的放大小地图布局。屏幕上的标记仍在「我的游戏小地图」里单独摆放。
- 如果博主的视频布局不同，点「新增布局」，输入名称（例如博主昵称），在浮窗拖动圆环、用滚轮调大小，然后点「完成」。圆环大致套住小地图即可，播放时程序会自动尝试对准圆心；需要时可手动重试。
- 当前布局跨视频和分 P 保持；可选择下次启动使用的布局。已有多个布局时，可在启动器或浮窗标题栏切换。**每帧只从当前一块视频区域识别**，红箭头和绿弧分别计算，不轮询其他布局。
- 旧版标定会迁成命名布局，可重命名使用；持续未识别到小地图时可切换或新增布局。

### 一个必须接受的局限

这是**够用级**方案，不是导航级：地形干扰、传送锚点图标、角色朝向 ≠ 行进方向（回头打怪时朝向立刻反向），都会让结果偏离。实测在正常游玩画面上误差约 ±10~20°，大方向可用，精确定位不行。

项目目录仅保存源码、文档、配置、测试工具和必要构建资源。`build/` 下的图标、安装器位图和许可属于产品资源，应保留；截图、实拍帧、视频、标注和实验报告不放入项目目录。

以本仓库目录为起点，外部目录约定如下（都不属于 Git 提交范围）：

| `../_materials/GIFA/vision-probe/reports/` | 视觉实验报告与门控标签归档 |

开发工具通过 `scripts/material-paths.js` 定位素材，默认路径不依赖启动命令所在目录；也可用环境变量 `GIFA_MATERIALS_DIR` 指定其他仓库外位置。截图、裁剪、抽帧和对照图输出均拒绝仓库内部路径。资源预览示例：`python scripts/make-assets.py --preview=../_preview`。

三份 `scripts/vision-probe/vid-times-*.json` 是抽帧参数配置，保留在项目中；本机视频位置等私有配置放在外部素材目录的 `vision-probe/video-conf.json`。现有 166/500 帧回归二进制数据仍读取系统临时目录，不会复制到仓库。`vid-times-roi.json` 默认导出 PNG，不能直接当作 166 帧二进制数据的重建命令。

可运行 `npm.cmd run test:materials` 检查路径边界，`npm.cmd run test:license` 检查许可一致性，`npm.cmd run test:cone` 检查视锥，`npm.cmd run test:snow` 检查雪地近白背景和用户视频抽样。`npm.cmd run test:bearing-view` 检查视角挂起及箭头漏检时视角独立上报。实拍数据缺失时须留意 `SKIP`；`test:autocenter` 需要本机 500 帧数据，完整测试依赖见问题清单。

`npm.cmd run test:controls` 验证按下/松开、物理重复去重、重挂后的释放屏障、快捷键冲突事务、沉浸窗口与鼠标避让、常规与临时倍率隔离；不启动业务应用、不读写用户配置。游戏内鼠标和权限行为仍需实机验收。

`npm.cmd run test:gamepad` 离线验证八方向触发、快速松开 L3、轮询异常退出、手柄断连和键鼠与手柄同时长按；游戏前台仍需实体手柄验收。

`npm.cmd run test:login` 离线验证登录入口不依赖浮窗、登录窗口前台显示、重复点击恢复、登录成功广播和轮询异步竞态；不连接 B 站、不读取用户配置。

`npm.cmd run test:sandbox` 验证沙箱启动失败兜底：先做离线回归，再用隔离的 Electron 和一个不存在的 `--gpu-launcher` 模拟 GPU 进程创建失败，检查记标记、带开关重启、兼容模式生效和失败对话框。测试数据放在系统临时目录并自动清理；模拟不能代替受影响系统上的实机验收。

`npm.cmd run test:playback` 验证音量、静音、倍速的保存和恢复：先做离线设置文件与 IPC 回归，再用隔离的 Electron 和本地媒体页面验证首次自动播放、换源、替换视频元素、页面重载和延迟创建视频。测试数据放在系统临时目录并自动清理，不启动业务窗口、不读取用户配置，也不连接 B 站；真实 B 站播放器的手动切 P、自动连播仍需实播验收。

## 已知限制

- 独占全屏下无法覆盖（请改成窗口化 / 无边框）
- 部分游戏使用 Raw Input 独占键盘，若快捷键失效，在设置里换成别的组合键
- 必须登录才有 1080P / 4K，未登录时 B 站自己只放预览或标清
- 网页版首屏比嵌入播放器慢一两秒
- 少数 Windows 环境在管理员权限下创建不了 Chromium 沙箱子进程（[上游问题](https://github.com/electron/electron/issues/49167)）。v0.2.5 之后的版本遇到时会自动以关闭沙箱的兼容模式重启一次并记住；仍然打不开时会弹出说明。启动诊断日志在 `startup.log`（安装版 `%APPDATA%\原神跟跑助手\`，绿色版 `data\`），反馈问题时请附上
